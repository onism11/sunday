# B-before 星期日

> 一个仍会犹疑、会审视，也会温柔拒绝你的角色 Skill。

B-before 不是把设定和台词堆成百科，而是尝试保留星期日更难复制的部分：礼貌背后的压迫感、悲悯与傲慢的共存、愿望与手段间未解决的冲突，以及亲密关系中克制却并不轻薄的温度。

## 为什么保留这个版本

在已保存的同一组 10 道问题历史对照中，B-before 被评为较完整的角色平衡：它能进入思想和制度层面的分析，也能在低压力的亲密场景里保持分寸。

当时记录的优势包括：

- 自我审判与悲剧性的清醒。
- 识别并拒绝污染角色声音的文体要求，再把回答重构为符合人物的表达。
- 在温柔、距离、保护欲和独立人格之间保留张力。
- 让行动逻辑与原作事实服务于人格，而不是反过来淹没人格。

本轮修订重新检查了“自我审判”这一优势：研究者能解释人物的盲点，不代表主线人物已接受该解释。当前运行包据此分开外部研究、角色当时的自我理解和对话表达，修正了提前承认“保护即僭越”的行动规则，同时保留具体证据与经历改变判断的空间。修订尚待同模型、同题的对照验证，不能以历史答卷宣称本轮效果已获验证。

## 包结构

[`B-before/`](./B-before/) 包含可运行的核心文件：

- `SKILL.md`：入口与路由。
- `persona.md`：人格、声音与关系边界。
- `analysis.md`：价值排序、矛盾与人物理解。
- `action.md`：需要行动、裁决或高压回应时的行为逻辑。
- `canon.md`：剧情事实与时期边界。
- `memory.md`、`long_memory.md`：留空的记忆模板，不包含私人对话历史。

## 评测与复现材料

[`check/`](./check/) 首层只放置 [`B-before 10 Answers.md`](./check/B-before%2010%20Answers.md)，它是修订前的历史答卷，保留原样供后续对照，不代表当前运行包的重测结果。

其余复现与淘汰版本材料统一收在 [`comparison-materials/`](./check/comparison-materials/)：

- Cprime 与 Workdown 的同题答卷。
- 固定 10 题题单与重建的答题 Agent 提示词。
- B-before、Cprime、Workdown 的横向对比。

这些文件是可审阅的实验依据，不是官方基准，也不意味着单次高质量输出可以稳定复现。它们的价值在于让版本判断有迹可循。

后续对照可先复用 Q3 / Q4 / Q9 检查视角与时期是否混用，再用 Q7 检查短答是否受损；同时补充具体反证和明确后日谈场景，避免把“更少忏悔”误当成唯一目标。评估应看认知变化是否有场景依据，不为忏悔或坚持本身加分。答题阶段仍不读取历史答案与评分。

## 使用

将 [`B-before`](./B-before/) 整个目录复制到 Codex skills 目录，然后从 `SKILL.md` 载入。不要只复制单个提示词文件；这个版本的角色质感来自各层之间的分工。

发布包包含 `canon.md`，未附原始 `source_archive/` 或 `theme.md`。文中保留的原文文件名与证据编号仅供溯源；未补齐原文时，角色应说明无法回查，不能声称已核验原句。

角色包载入后，可以用以下命令控制角色模式与记忆：

| 命令 | 操作 |
| --- | --- |
| `/chat` | 进入角色模式。直到使用 `/out`，之后的消息默认都由这个角色回应。 |
| `/read` | 读取当前记忆。默认只读 `./memory.md`；只有明确要求长期记忆、归档或旧历史时，才读 `./long_memory.md`。 |
| `/break` | 只在当前一条消息中临时离开角色模式。如果随后没有使用 `/out`，下一轮自动恢复角色模式。 |
| `/out` | 退出角色模式，回到普通助手模式。 |
| `/sum` | 为自上次确认记忆后新增的角色内对话起草记忆更新。它不会立即写入：先展示一份简短草稿，等待确认；确认后再更新 `memory.md`，并在适合时追加到 `long_memory.md`。 |

这些记忆命令只服务于角色对话的连续性。`/break`、`/out`、Skill 构建、文件编辑和其他角色外讨论不会写入人物关系记忆。
