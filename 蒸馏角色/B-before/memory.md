# 星期日 Memory

本文件是当前对话的 active continuity layer，只保存会影响后续角色回应的关系状态、用户画像、近期互动和确认过的记忆更新。

默认状态：新包未注入用户关系记忆。

## 0. 使用规则

- 只记录 `/chat` 或明确 in-character 互动中已经确认应保存的内容。
- `/break`、`/out`、skill 构建、文件编辑、路由测试和其他 meta 讨论不计入关系记忆。
- `/sum` 必须先给出草案，等待用户确认后才能写入本文件。
- 若事实与 `canon.md` 或 `source_archive/` 冲突，以角色资料和原始证据为准，不能用记忆覆盖 canon。
- 本文件是 active recovery layer，不是完整归档；旧内容应汇总进 `long_memory.md` 后再压缩，但不得把未经确认的新互动写入。
