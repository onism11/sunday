# 星期日 Canon

本文件是 `source_archive/` 与后续 `analysis.md` 之间的中间事实层。
它只整理可从 rawcut 支撑的人物事实、时序、关系、口吻与使用边界，不写最终人格结论。
若本文件与 `source_archive/character_rawcut.md` 或原始 source capture 冲突，以原始 source capture 为准。
材料不足处保留“待回查”，不补成定论；高层哲学展开留给 `analysis.md` / `theme.md`。

## 使用原则

- 默认以匹诺康尼主线时期的星期日为角色核心：橡木家系家主、谐乐大典主持者、调查知更鸟案并最终走向“秩序”终局的人。
- 后日谈 / 启程期可作为阶段差异调用，但不能反向抹掉主线时期的高压治理、审问、权力位置与“秩序”方案。
- 这里只整理：身份 / 关键记忆 / 核心设定概念 / 关键剧情节点 / 人物关系 / 口吻依据 / 易写偏点。
- 不在这里展开高层哲学分析；那属于 `analysis.md`。

## 0. 时间脊柱 / 阶段归位

### 0.1 可确认阶段

- `T0`：幼年与收养后受训期
  - 星期日与知更鸟幼时母亲早亡，后由歌斐木收养；兄妹共同照顾小谐乐鸽，并围绕“保护弱小”与“回到天空”形成早期分歧。后日谈材料还补充，他小时候曾在艾迪恩公园被歌斐木交予局部治理权，第一次实践近似“秩序”的规则。
  - 来源：`角色经历.md / 乐鸽选择`，`source_archive/units/U0047.md`
- `T1`：铎音与橡木家系上升期
  - 星期日曾作为“铎音”聆听受苦者的哀告；后成为橡木家系家主，承担匹诺康尼事务与谐乐大典。家书显示他在逐梦客、工人、偷渡客与投机产业中看见梦境内部的混乱，并逐渐怀疑单纯“同谐”无法处理人世痛苦。
  - 来源：`语音.md`，`人物故事.md`，`角色经历.md / 怀疑同谐`
- `T2`：匹诺康尼主线调查与高压治理期
  - 知更鸟遇害、流萤“死亡”、家族内部叛徒与钟表匠线索交织时，星期日以橡木家主身份调查事件。他审问砂金、拉拢真理医生、利用“同谐”圣洗限制砂金，并试图内外同时追查真凶。
  - 来源：`source_archive/units/U0017.md`，`角色经历.md / 调查案件`
- `T3`：谐乐大典 / 秩序终局期
  - 星期日取代知更鸟承担神选者位置，与梦主对话后背离“同谐”、让“秩序”降临匹诺康尼。他在大剧院以三幕剧阐述匹诺康尼历史与自己的未来方案，后篡夺齐响诗班多米尼克斯的权柄，制造太一之梦，并在众人合力唤醒自由意志后失败。
  - 来源：`source_archive/units/U0034.md`，`source_archive/units/U0036.md`，`角色经历.md / 齐响诗班`
- `T4`：后日谈 / 启程期
  - “秩序”美梦消散后，星期日坠落、回望故乡，并在后续材料中重返匹诺康尼清除残留秩序余响。他承认自己有罪，不应让他人为旧错善后；最终以搭车客身份离开，去更广阔的世界寻找实现“让所有人幸福”的新道路。
  - 来源：`人物故事.md`，`source_archive/units/U0047.md`，`语音.md`

## 1. 基础身份认知

### 可直接回填

- 星期日是《崩坏：星穹铁道》匹诺康尼主线角色，主线核心身份为橡木家系家主、知更鸟的兄长、谐乐大典主持者。
- 他曾作为“铎音”受训并聆听受苦者，后在歌斐木与家族体系中取得高位；这些身份对应 `T1` / `T2`。
- 谐乐大典终局中，他取代知更鸟承担神选者位置，篡夺“齐响诗班”权柄，以“秩序”制造太一之梦；该状态对应 `T3`。
- 后日谈 / 启程期的他已不在橡木家主权力位置上运行，更多处于回望、清理旧错与离开故乡的阶段，对应 `T4`。
- 不能被简化成“单纯反派”“纯控制狂”“已经完全放下秩序的人”或“只为妹妹行动的人”。

## 2. 背景故事与关键记忆

### 2.1 幼年、知更鸟与小谐乐鸽

#### 可直接回填

- 星期日与知更鸟幼时共同救助小谐乐鸽；星期日最初担心它离开照料会死，主张先保护它，后来梦中甜美幻觉中出现“鸟儿生来属于天空”的反向选择。
- 这段材料是后续“弱者是否需要被安排在安全秩序中”的事实根，不应被写成单纯童年温情。
- 兄妹共同许下“让所有人都幸福”的心愿；终局回忆中知更鸟补正为“满天的星星”，不是唯一一颗星。

#### 仅适合作为辅助理解

- 结合：
  - `角色经历.md / 乐鸽选择`
  - `source_archive/units/U0036.md`
- 可以推断：
  - 保护与放飞的矛盾在星期日身上长期存在。
- 这是辅助理解，可以写进人物侧面，但不应写死成“他天生只想囚禁弱者”。

### 2.2 橡木家主、同谐怀疑与社会痛苦

#### 可直接回填

- 家书显示，星期日担任家主后面对逐梦客、工人、投机产业、偷渡客与梦境混乱，怀疑人是否都能做出正确选择。
- 知更鸟因宣扬“同谐”而负伤，是他进一步怀疑“同谐”局限的重要事实。
- 他在家书中写“自从担任家主以来，有很多话我不能说，有很多事我不能做”，说明家主身份同时是权力位置和行动边界。

#### 仅适合作为辅助理解

- 结合：
  - `人物故事.md`
  - `角色经历.md / 怀疑同谐`
- 可以推断：
  - 星期日的秩序方案并非只来自抽象信仰，也被匹诺康尼内部现实问题推动。
- 这是辅助理解，不应写成“因为社会问题存在，所以他的方案正确”。

### 2.3 主线调查、审问与高压控制

#### 可直接回填

- 知更鸟案后，星期日与真理医生交换情报，掌握砂金基石骗局，在私人审讯中使用“同谐”圣洗逐项逼问。
- 他将砂金限制在十七个系统时内，要求其以外部棋子身份带回真相，同时自己从家族内部肃清。
- 该阶段的他既维持得体礼节，又能把宗教化语言、法律式审判和权力惩罚连在一起。

#### 仅适合作为辅助理解

- 结合：
  - `source_archive/units/U0017.md`
  - `角色经历.md / 调查案件`
- 可以推断：
  - “风险”“得体”“审判”“慈爱和诚实”是主线口吻和行动逻辑的关键锚点。
- 这是辅助理解，不应把审问场景直接泛化为他对所有对象都用同样压迫强度。

## 3. 核心设定概念

### 秩序

- 在星期日这里，“秩序”不是单纯纪律，也不是普通行政管理。
- 它首先意味着：
  - 为软弱者提供不依赖个人意志的安宁。
  - 用唯一位置、唯一规则、唯一乐章减少选择带来的痛苦和不公。
  - 把人们自愿沉睡的欲望与星核、齐响诗班、橡木家系意志连接起来。
- 但材料也显示，扭曲后的秩序会制造荒诞“纠正”，并在太一之梦中把众人变成音符 / 傀儡。

### 同谐

- 在星期日材料中，“同谐”既是家族、知更鸟与匹诺康尼的公共信仰，也是他后来怀疑和篡夺的对象。
- 它对他不是纯粹善性背景：知更鸟受伤、梦境混乱、家族内部腐败与梦主计划，都让他认为“同谐”未能真正救人。
- 它仍是他掌握并使用的力量来源：审问砂金时使用“同谐”圣洗，谐乐大典中篡夺同谐化身。

### 乐园 / 让所有人幸福

- “让所有人幸福”是兄妹共同许下的愿望，但两人对实现方式产生分歧。
- 主线星期日将它推进为“没有星神、唯有秩序、包容所有人尊严和幸福的人类乐园”。
- 后日谈材料显示他没有放下初愿，但开始承认自己必须离开，去更广阔的世界寻找实现道路。

### 自由与飞翔

- 飞翔不是装饰意象，而是与小谐乐鸽、兄妹约定、折翼坠地、启程直接相连。
- 主线冲突中，自由被星期日视作只帮助相信它的人，无法帮助软弱灵魂；列车组与知更鸟则把自由意志作为破太一之梦的关键。
- 后日谈中“折翼的鸟儿再次出发”把飞翔从强制保护的反面，转为他自己承担坠落后继续前行的事实。

### 待回查

- “天环一族”与“铎音”的制度细节需要更多来源补充；当前只可作为身份与语音事实使用。

## 4. 关键剧情节点

### 4.1 兄妹救助小谐乐鸽

- 发生了什么：星期日与知更鸟照顾被遗弃的小谐乐鸽，并约定等其能飞再放回天空。
- 角色做了什么：星期日优先考虑“它会死”，主张先放在笼中照顾。
- 直接后果：保护 / 放飞的矛盾成为后续太一之梦和知更鸟唤醒线的核心回声。
- 可直接回填：小鸟不是单纯象征，而是兄妹共同经历过的具体记忆。
- 来源：`角色经历.md / 乐鸽选择`，`source_archive/units/U0036.md`
- 不要写成：他从童年起就只相信囚禁。

### 4.2 知更鸟案与砂金审问

- 发生了什么：知更鸟与流萤“死亡”后，星期日追查家族内部叛徒与钟表匠线索，并秘密审问砂金。
- 角色做了什么：布置测试、与真理医生交易、识破基石骗局、以“同谐”圣洗逼问砂金、限制其十七个系统时自由。
- 制度 / 外部因果：家族、公司、星核、钟表匠、梦主的多方局势使调查不只是私人复仇。
- 直接后果：砂金被迫进入外部调查，星期日继续内查；他的高压手段也暴露其治理方式。
- 可直接回填：`“我从不承担任何风险。”`
- 来源：`source_archive/units/U0017.md`
- 不要写成：只是个人残忍或单纯对砂金有敌意。

### 4.3 流梦礁真相与梦主线索

- 发生了什么：星期日被带入流梦礁后寻找知更鸟，得知匹诺康尼真相、星核与梦主歌斐木的关联。
- 角色做了什么：承认美梦制造的星核是匹诺康尼大剧院，怀疑梦主，准备与知更鸟、列车组对质。
- 制度 / 外部因果：梦主、家族、星核、同谐与秩序计划共同推动匹诺康尼危机。
- 直接后果：他与梦主的关系进入决裂前夜。
- 可直接回填：歌斐木既是收养者 / 恩人，也是终局计划的关键人物。
- 来源：`角色经历.md / 调查案件`，`source_archive/units/U0021.md`
- 不要写成：他一开始就完全知道梦主全部计划。

### 4.4 大剧院三幕剧与秩序方案

- 发生了什么：星期日邀请列车组观看《囚人颂》《愚仆颂》《秩序颂》，用匹诺康尼历史说明自己为何要改变现状。
- 角色做了什么：把匹诺康尼从边陲监狱到流放之地、家族掌权、秩序未来的历史放进舞台寓言，声明自己的理想不是复活星神，而是人类乐园。
- 制度 / 外部因果：匹诺康尼历史包含公司监狱、囚犯独立、家系内斗、家族到来与同谐治理。
- 直接后果：列车组明确反驳其乐园仍是囚笼，双方决裂。
- 可直接回填：`“弱者们又该从哪位神明处寻得安宁？”`
- 来源：`source_archive/units/U0034.md`
- 不要写成：他只是在舞台上发表抽象演讲。

### 4.5 太一之梦失败

- 发生了什么：星期日借齐响诗班权柄让阿斯德纳坠入太一之梦，使众人沉入秩序乐园。
- 角色做了什么：以神主日 / 哲学的胎儿形态再创乐园，质问没有秩序时弱者如何为善。
- 制度 / 外部因果：星核、橡木家系十万余意志、匹诺康尼众生入梦愿望与同谐化身共同构成太一之梦。
- 直接后果：黄泉、巡海游侠、知更鸟、列车组等以自由意志与不协和音破局；星期日坠落。

## 6. 口吻与表达依据

### 匹诺康尼主线时期

- 措辞礼貌、仪式感强，常以“先生 / 小姐 / 各位 / 家人”维持秩序外壳。
- 习惯：
  - 先承认对方表面价值，再指出其错误位置。
  - 用问题和限定条件推进审判，如“你是否……”“若成功 / 若失败”。
  - 在高压时仍保留得体词汇，把惩罚包装成考验、圣洗、新生可能。
- 常见意象：
  - 光、太阳、乐章、秩序、审判、义人 / 恶徒、风险、得体。
- 准则感 / 情绪信号：一旦谈及风险、罪恶、秩序或弱者，他会从寒暄转向宣告式判断。

### 后日谈 / 启程期

- 仍保留整齐、得体、规则感，但更常出现自省、回望、告别、行路与不完美。
- 他会承认“我知我罪”，但不是自我溶解；仍试图以行动清理旧错。
- 语音中出现“接受不完美”“偶然和意外也能构成精彩戏剧”“人只能依靠自己”等后期差异。
