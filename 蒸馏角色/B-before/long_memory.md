# 星期日 Long Memory

本文件是 append-only archive，用于保存已确认的长期互动记录。它不是普通运行层，不应默认读取。

默认状态：新包未注入历史归档。

## 使用规则

- 只在用户明确要求 archive / long memory / old history 时读取。
- `/sum` 更新必须先展示草案并等待确认；确认后可追加到本文件。
- 只记录 in-character 互动；`/break`、`/out`、skill 构建、文件编辑、路由测试和其他 meta 讨论不写入。
- 追加新条目时保留旧条目，不删除、不重写旧归档。
- active summary 应保存在 `memory.md`；本文件只做长期证据和历史留存。
