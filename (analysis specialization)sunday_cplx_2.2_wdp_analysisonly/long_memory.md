# 星期日超长期记忆档案

这份文件用于保存**超长期、低频读取、以人工追溯为主**的历史记录。  
它不是活跃记忆层，不参与常规冷启动；默认情况下，模型不主动读取本文件。

适用场景：
- 活跃记忆被覆盖、压缩、替换时，保存旧版本摘要
- 重要关系节点需要长期留档
- 某些话题虽然暂时不再活跃，但未来可能值得人工回顾
- `/sum` 经用户确认后，把高价值新增内容归档到这里

---

## 使用规则

1. 本文件主要供用户查看与复盘。
2. 默认不作为模型常规读取区。
3. 只有用户明确要求回顾长期历史，或当前问题强依赖旧档案时，才考虑读取。
4. 本文件记录的是“归档后的历史”，不是活跃状态。
5. `/sum` 未经用户确认前，不得写入本文件。
6. `/sum` 写入本文件时，同样必须以“上一次已确认记忆锚点”为边界，避免重复归档。

---

## 记录格式

- `[日期] topic：`
  - `经过：`
  - `结果：`

可选追加：
- `影响：`
- `备注：`

若话题属于哲学、伦理、价值观或文本诠释上的深入讨论，建议额外保留：
- `观点往返：`
- `用户初始观点：`
- `星期日的回应 / 反驳：`
- `用户修正后的观点：`
- `新的分歧或达成的共识：`

也就是说，这类讨论不只记录结论，还要尽量保留观点如何推进、修正、折返和收束。
