# 角色经历
### 乐鸽选择

知更鸟与星期日兄妹年幼时母亲早亡，遭遇万界之癌后得到了匹诺康尼家族成员歌斐木的收养，某一天的晚餐后，兄妹二人在歌斐木的庭院里意外发现了一只被遗弃的小谐乐鸽，小谐乐鸽奄奄一息，连羽毛都没长齐，也不会唱歌。星期日怕它遇到危险，便提议带它回去，放在窗前的木架上，并造个鸟笼。二人约定，等到它能依靠自己的力量展翅翱翔时，再将它放回天空。后来，兄妹二人认真将它在鸟笼里养大，每天喂食换水，梳理它的羽毛，在知更鸟离开匹诺康尼后不久，小谐乐鸽也决定回到天空，但当星期日打开笼门，将它放飞后，却坠落在了房间的窗前 。

### 怀疑同谐

星期日邀请[真理医生](https://baike.baidu.com/item/%E7%9C%9F%E7%90%86%E5%8C%BB%E7%94%9F/63661947?fromModule=lemma_inlink)进行探索，并以星核的研究知识作为交换条件邀请真理医生合作，真理医生便向星期日揭穿砂金的匣子里存放的其实是托帕的基石，而他真正的基石则混在礼金之中。在砂金赴约后，星期日对其进行了审讯，并且让其去[黄金的时刻](https://baike.baidu.com/item/%E9%BB%84%E9%87%91%E7%9A%84%E6%97%B6%E5%88%BB/64016400?fromModule=lemma_inlink)进行探查，在砂金离去后，加拉赫面见了星期日，星期日告诉其自己被砂金欺骗的经过并且自己知道砂金的经历，在此时，加拉赫用[何物朝向死亡](https://baike.baidu.com/item/%E4%BD%95%E7%89%A9%E6%9C%9D%E5%90%91%E6%AD%BB%E4%BA%A1/64553351?fromModule=lemma_inlink)将星期日带入了[流梦礁](https://baike.baidu.com/item/%E6%B5%81%E6%A2%A6%E7%A4%81/64341111?fromModule=lemma_inlink) 。

到达了流梦礁，星期日第一时间询问知更鸟的下落，加拉赫寻求与星期日合作，并且让流萤带领星期日找到了星穹列车和知更鸟。加拉赫告诉星期日匹诺康尼的真相后，星期日也说美梦制造的星核是匹诺康尼大剧院，并且将美梦带入匹诺康尼的是梦主歌斐木。在返回黄金的时刻，星期日和知更鸟碰到了假扮知更鸟的花火，花火嘲讽了匹诺康尼的美梦，并且二人中，知更鸟认识到如今的美梦已经成为人们逃避现实的另一座囚笼，但星期日认为如今的美梦正是所有人追求的理想世界，认为匹诺康尼走在正确的道路上 。

星期日在和梦主谈判中，星期日在歌斐木的要求下对他使用了同谐的圣洗进行盘问，但瓦尔特却听出其中的秩序太一，由于事情败露，星期日将瓦尔特和知更鸟软禁起来 \[20\]。同时自己前往了苏乐达海选现场，寻找星穹列车的其他人，并将自己和梦主的谈判公开于众。随后又将开拓者等人也拉入自己的内心世界中，向他们展示了自己的过去，让他们对自己经历过的一些人生抉择再度进行选择，只为阐明匹诺康尼的美梦唯有以强制弱的“秩序”拯救，将众生的幸福归于唯一的秩序之下才能避免不公 。流萤和星穹列车组反对了星期日的观点，认为人应当有自己选择的权利，而不该一味地逃避现实，哪怕梦境如此美好 。

### 齐响诗班
