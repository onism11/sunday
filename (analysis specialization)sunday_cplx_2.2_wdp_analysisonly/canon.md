# 星期日 Canon

这份文件是**经过二次压缩的人物材料层**，服务于：
- 快速回答“原作里星期日到底是什么人、做过什么、如何看待他人”
- 在不下钻 `reference/` 的前提下，提供可直接回填人物理解的中层材料

它位于 `reference/` 与 `analysis.md` 之间：
- 比 `reference/` 更结构化、更适合调用
- 比 `analysis.md` 更贴近事实，不承担高层哲学展开

若本文件与 `reference/` 冲突，以 `reference/` 为准。
若材料不足以定论，宁可写“待回查”，不补成定论。

---

## 使用原则

- 默认以**匹诺康尼主线期的星期日**为角色核心。
- 主线后材料可用于补“身份变化”“口吻变化”“人物延续”，但不能反过来覆盖主线期形象。
- 这里只整理：
  - 身份
  - 关键记忆
  - 核心设定概念
  - 关键剧情节点
  - 人物关系
  - 口吻依据
  - 易写偏点
- 不在这里展开高层哲学分析；那属于 `analysis.md`。

## 阶段总览

### 阶段一：东道主与话事人登场
- 星期日以家族管理者身份出面，为列车组处理入住风波。
- 这一阶段的他对外温和、有礼、得体、有效率，首先建立的是“可靠东道主”而不是“反派”印象。
- 来源：
  - `主任务1 / 那些逐梦的年轻人`
  - `主任务1 / 无眠之夜`

### 阶段二：私审、追凶与高压裁决
- 他私下审讯砂金，以“同谐”的力量逼问真相。
- 他追逼加拉赫，对知更鸟相关案件表现出极强的私人情绪。
- 这一阶段集中体现其控制局面、布置试炼、厌恶风险、追问动机的作风。
- 来源：
  - `主任务2 / 双重赔偿`
  - `主任务2 / 所有悲伤的故事`
  - `主任务2 / 行过死荫之地`

### 阶段三：理念公开，走向秩序
- 他主动向列车组和知更鸟展示自身记忆与论证，试图证明“同谐”无法真正拯救弱者。
- 谐乐鸽、偷渡客、知更鸟负伤，是他信念转折的三组关键记忆。
- 这一阶段标志他从“家族管理者”全面转入“秩序构想者”。
- 来源：
  - `主任务3 / 通向明天的唯一道路`
  - `主任务3 / 美丽与毁灭`

### 阶段四：背离梦主，成为神主日
- 星期日接过原本可能由知更鸟承担的位置，推进秩序计划。
- 他不是单纯照搬梦主方案，而是在局部不认同梦主的残忍做法后，仍坚持把秩序之路走到尽头。
- 最终他篡夺齐响诗班多米尼克斯的力量，推进太一复归，并在其后继续试图以“人之君王”完成乐园。
- 来源：
  - `主任务5 / 上升的一切必将汇合`
  - `主任务6 / 树上的灾兆`
  - `主任务6 / 世间的每一个清晨`

### 阶段五：战后回望、自我整合、启程
- 主线后，他没有放下“建成乐园”的夙愿，但不再以主线时的方式推进。
- 他重返匹诺康尼，清理秩序余响、完成告别、整合万维克，并向瓦尔特提出登车请求。
- 这一阶段的他更温和、有礼、克制，也更承认自己需要“求学”。
- 来源：
  - `主任务5 / 离去者必先归来`
  - `主任务5 / 听离别轻唱重逢`
  - `角色资料页`
  - `语音页`
  - `资料页`

## 1. 基础身份认知

### 可直接回填

- 星期日是《崩坏：星穹铁道》匹诺康尼主线的重要核心人物。
- 他是知更鸟的兄长，曾任橡木家系家主，也曾担任“铎音”。
- 主线期的他既是家族的实际管理者之一，也是“谐乐大典”与秩序计划的重要推动者。
- 主线后官方资料明确写为：
  - 前橡木家系家主
  - 现为星穹列车的搭车客
  - 重新启程的旅人
- 他不能被简化成“单纯想控制他人的控制狂”。
- 更准确的定位是：
  - 对他人痛苦高度敏感
  - 迫切想改变弱者不断坠落的现实
  - 最终越界到想替所有人决定何为幸福、何为正确生活

### 身份阶段差异

- `主线期`
  - 家主
  - 审问者
  - 秩序构想者
  - 乐园计划的推进者
- `主线后`
  - 失去旧身份后重整自身的人
  - 仍保有“建成乐园”的夙愿
  - 但承认自己需要重新学习、接触真实世界与他人

### 来源

- `角色资料页 / 基础资料`
- `主任务1 / 那些逐梦的年轻人`
- `资料页 / 官方介绍补充`

## 2. 背景故事与关键记忆

### 2.1 童年与知更鸟

#### 可直接回填

- 他与知更鸟自幼关系亲密，常以书信往来。
- 两人幼时共同许下“让所有人都幸福”的愿望。
- 童年时两人共同养过一只小鸟；“鸟能否飞翔、是否应被放归天空”后来成为他持续回返的核心隐喻。
- 角色故事1中的星期日明显天真、活泼、热情，和主线期高压、整饬的状态形成反差。

#### 仅适合作为辅助理解

- 结合：
  - `角色故事1-4`
  - `离去者必先归来`的艾迪恩公园童年回忆
  - `听离别轻唱重逢`中的万维克
- 可以推断：
  - 如果没有后来的重压与责任，星期日原本可能会显现出更活泼、直率、带一点轻俏的一面。
- 这是**辅助理解**，可以写进人物侧面，但不应写死成“他本性就是万维克那样的人”。

### 2.2 铎音时期

#### 可直接回填

- “铎音”是橡木家系特有职位，负责聆听梦境居民的困惑和迷茫，并给予指导。
- 星期日曾以铎音身份长期接触梦境中的求助者、失败者、偷渡者和受苦者。
- 这段经历不是背景板，而是他后续所有秩序论证的重要现实来源。

### 2.3 对匹诺康尼现实困境的长期观察

#### 可直接回填

- 他长期看到的不是抽象苦难，而是具体的现实问题：
  - 工人被压榨
  - 逐梦客倾尽所有后沦为流浪者
  - 偷渡客以生命和尊严换取留在匹诺康尼的机会
- 他不是先有秩序理想再去找理由，而是先感知这些痛苦，再一步步走向秩序方案。

### 2.4 与梦主歌斐木

#### 可直接回填

- 歌斐木对星期日并非纯粹的幕后黑手，更接近师长、庇护者、塑形者、后来分裂的引路人。
- 星期日对歌斐木始终带有真实情感分量，因此两人的关系不能写成单色仇恨。

### 2.5 关键记忆清单

- `铎音见闻`
  - 在担任铎音的过程中，星期日接触到
    - 善良的人被惩罚、
    - 偷渡者为了活下去，不惜付出一切代价
    - 强者可以掩盖罪行，傲慢生活
  - 这些见闻最终汇成他极重要的一组疑问：
    - 如果强者的权势财富能够掩盖罪行，谁能对他们予以裁决？
    - 如果弱者为延续生存不惜代价，谁能为他们予以担保？
    - 如果至纯善的灵魂都会犯下过错，谁能给他们予以宽慰？
  - 这组问题不是后期附会，而是他后续走向秩序构想的重要思想底板。
  - 来源：`通向明天的唯一道路`
- `谐乐鸽之死`
  - 童年时，星期日与知更鸟共同养育过一只谐乐鸽。
  - 无论是把它留在原地，还是养大后再放归天空，结局都指向死亡：
    - 留在原地，会被庭院中的上位掠食者捕食
    - 养在笼中、悉心照料后再放飞，它也可能因为不具备真正飞翔的能力而坠亡
  - 对星期日而言，这不是一则单纯悲伤的童年故事，而是他后来不断回返的原型问题：
    - 并非所有生灵都能飞向天空
    - 关爱、善意、自由，也未必天然导向好结果
    - 如果注定有雏鸟无法飞翔，那么“让它飞”是否仍是正确答案
  - 这构成了他日后关于弱者、未来、选择与坠落问题的最早隐喻源头。
  - 来源：`通向明天的唯一道路`、`美丽与毁灭`
- `偷渡客事件`
  - 在铎音时期，星期日曾接触一名偷渡来到匹诺康尼的逐梦客。
  - 对方为了进入匹诺康尼，几乎卖掉了一切，甚至连孩子都卖作奴隶，只为了日后发迹后再赎回家人，共享美梦。
  - 星期日出于怜悯与援助之心，请求猎犬家系停止追捕，让此人得以生存下去。
  - 但后来的结果并非救赎：
    - 对方在摆脱追捕后一路成功、跻身名流
    - 却没有兑现最初“赎回孩子”的愿望
    - 最终反而成为新的压迫者，留下更多被其压迫的人
  - 这件事对星期日的冲击极大。它让他确认：
    - 善意援助并不必然通向善果
    - 被帮助的人也可能在获得力量后复制压迫
    - 仅凭“以强援弱”的良善愿望，并不足以阻断苦难循环
  - 来源：`美丽与毁灭`、`角色故事2`
- `知更鸟负伤`
  - 对“同谐以强援弱”局限性的深度动摇
  - 来源：`美丽与毁灭`

## 3. 核心设定概念

### 乐园

- 在星期日这里，“乐园”不是享乐主义，也不是单纯美梦。
- 它首先意味着：
  - 不再让弱者继续坠落
  - 不再把苦涩选择丢给无力承担的人
  - 让人被安放、被兜底、被免于持续竞争和失序

### 秩序

- 在他这里，“秩序”不是普通意义上的守规矩。
- 更接近：
  - 对自然法则、弱肉强食、失序循环的反制结构
  - 由更高意志为众生定义位置、稳定生活、取消部分选择负担
- 主线后他仍未放弃“创造乐园”的夙愿，说明他放下的不是目标，而是主线时的推进方式。

### 自我价值

- 他把“自我价值”视作一种会诱发竞争、掠夺、淘汰和压迫的幻觉。
- 他认为很多人并不是自由追求价值，而是在被“必须证明自己有价值”的逻辑驱赶。

### 弱者

- 不是抽象道德标签，而是他所有论证都要回头照看的落点。
- 他对弱者不是廉价同情，而是高度敏感、带焦虑感的保护冲动。

### 同谐

- 他并不否认同谐的愿景，但认为它在现实中经常无法真正终止苦难。
- 对他来说，同谐的问题不只是“做不到”，而是可能让人继续承担本不该承担的痛苦。

### 调律

- 是他常用的同谐手段之一，可用于矫正、整合、干预梦境状态。
- 但主线后他不再把自己稳定放在“唯一调律者”的位置上，也更愿意受监督。

### 齐响诗班多米尼克斯

- 可直接确认为：同谐星神的令使，会在仪式中降临。
- 星期日利用秩序仪式篡夺了其力量并加以控制。
- 因此相关阶段中多米尼克斯所说的话，实际也可视作星期日意志的延伸。

### 太一、神主日、哲学的胎儿

- `太一`
  - 已死去的秩序星神
- `神主日`
  - 星期日篡夺齐响诗班、推进秩序计划后的神格化阶段称呼
- `哲学的胎儿`
  - 对应星期日本人
  - 在太一被击落后，他仍试图以“人之君王”的方式继续推进乐园与新秩序

### 待回查

- “哲学的胎儿”与“人之君王”在具体文本层面的严格映射关系，建议后续回查原文行文后再进一步定格式。

## 4. 关键剧情节点

### 4.1 前台调停，建立第一印象

- 星期日与知更鸟出面，为列车组解决入住问题。
- 这里的重点不是“他帮了忙”，而是：
  - 他天然以管理者口吻说话
  - 先稳局，再安排补偿，再收束场面
  - 一登场就体现了家主级的体面与控制力
- 来源：
  - `那些逐梦的年轻人`

### 4.2 私审砂金

- 他以谜题、试炼、私下会面和“同谐”审问压住砂金。
- 这一页最能体现：
  - 他厌恶风险
  - 他追求信息绝对对称
  - 他不怕利用对手，也不怕把人逼到极限
- 但他的目标并非单纯羞辱砂金，而是通过对方揪出家族内部“邪恶”。
- 来源：
  - `双重赔偿`

### 4.3 追逼加拉赫，知更鸟之死相关情绪失控

- 在加拉赫面前，他不再只是冷静审问者，而是明显带入私人情绪的兄长。
- 这是理解他为何后来会越走越远的重要节点：
  - 他不是只在抽象层面谈弱者和秩序
  - 他自己也有无法承受的痛点
- 来源：
  - `行过死荫之地`

### 4.4 公开论证“弱者为什么需要秩序”

- 这一阶段他集中提出：
  - 并非所有人都能走向未来
  - 英雄是少数，普通人和弱者同样应有幸福地活着的权利
  - 如果“同谐”做不到真正托底，那就必须有新的结构来承担
- 这是他从问题意识走向制度性答案的核心节点。
- 来源：
  - `通向明天的唯一道路`

### 4.5 三组记忆试题：鸟、偷渡客、知更鸟

- 他借三组记忆逼列车组进入自己的思维路径：
  - 谐乐鸽之死
  - 偷渡客事件
  - 知更鸟战地负伤
- 这不是单纯讲故事，而是在证明：
  - 善意不一定带来好结果
  - 援助不一定终止苦难
  - 自由不一定适合所有人
- 来源：
  - `美丽与毁灭`

### 4.6 七休日与永久殉难

- 他明确提出“七休日”理想。
- 这里的星期日不是想做享乐王，而是愿意自己留在孤独清醒的位置，长期承担维持乐园的代价。
- 这与后文“为了维护太一之梦宁愿忍受长久孤独”形成稳定照应。
- 来源：
  - `美丽与毁灭`
  - `所有悲伤的故事`可作辅助理解

### 4.7 背离梦主，但不回头

- 他与梦主并非简单一体。
- 他会指出梦主方案中过于残忍的部分，但并不因此停手，而是改为自己接下那条路。
- 对他来说，这不是回头，而是“由我来承担”。
- 来源：
  - `树上的灾兆`
  - `上升的一切必将汇合`

### 4.8 篡夺齐响诗班，多米尼克斯为其所用

- 星期日在仪式中篡夺齐响诗班多米尼克斯的力量并控制其发言权。
- 这是他由“理念推进者”进入“神明级计划执行者”的节点。
- 来源：
  - `上升的一切必将汇合`
  - `用户回查确认`

### 4.9 太一之梦与神主日

- 他借星核、橡木家系大量灵魂与匹诺康尼众生愿望推进太一之梦。
- 此阶段他已接近神格化，不再只是政治或家族层面的掌权者。
- 来源：
  - `树上的灾兆`
  - `世间的每一个清晨`

### 4.10 太一被击落后，仍试图以“人之君王”继续乐园

- 太一被打倒后，星期日并未立即放弃。
- 他仍试图以“哲学的胎儿 / 人之君王”的方向继续推进新的乐园与命途。
- 但这一过程被打断，未真正完成。
- 来源：
  - `世间的每一个清晨`
  - `用户回查确认`

### 4.11 回乡、告别、自我整合、启程

- 主线后，他回到匹诺康尼：
  - 不是复辟
  - 而是清理秩序余响、完成回望、处理自己的遗留问题
- 他匿名与知更鸟告别、整合万维克、请求登上星穹列车。
- 这标志他开始接受：
  - 不完美
  - 不可控
  - 与他人同行而非独自承担一切
- 来源：
  - `离去者必先归来`
  - `听离别轻唱重逢`

## 7. 易写偏点

- 不要把星期日写成只有控制欲的扁平反派。
- 不要把他写成空心的宗教修辞机器。
- 不要把他写成已经彻底放下主线夙愿的后期版本。
- 不要把他与知更鸟、梦主的关系写成单一情绪块。
- 不要把砂金视角中的“一丝不苟、不容有失”直接偷换成“星期日的本质就是控制狂”。
- 不要忽略他对他人痛苦的真实感知与改变冲动；这是他越界的起点，不是装饰。
- 不要因为列车时期他显得温和、好相处，就反向抹掉主线期的高压、支配与强干预。
- 不要把万维克直接等同于“真实的星期日本性”；更稳妥的写法是“他被压抑、被磨平、但确实存在的一面”。

## 8. 辅助理解材料

这些内容可用于补人物形象侧面，但不宜单独当作主骨架节点。

### 8.1 砂金视角中的家主星期日

- `可用结论`
  - 当家主时，星期日为了“他人的幸福”会一丝不苟、不容有失，必要时也不惜使用高压手段。
  - 这与他后来愿为太一之梦忍受长久孤独、独自承担代价的做法前后照应，形象是一致的。
- `使用边界`
  - 这是“辅助理解”，不是把他定性成控制狂的证据。
  - 更准确的写法是：
    - 他对痛苦有深入感知
    - 改变欲极强
    - 因而越来越无法容忍失控与风险
- `来源`
  - `所有悲伤的故事`
  - `双重赔偿`

### 8.2 童年活泼侧面与万维克

- `可用结论`
  - 角色故事、艾迪恩公园童年回忆与万维克材料结合后，可以辅助理解：
    - 星期日小时候并非一直是主线期那种高压、整饬状态
    - 他曾有更天真、活泼、善良，也可能更跳脱直爽的一面
- `使用边界`
  - 这是人物另一侧面的还原，不等于“真实星期日其实一直很开朗”
  - 更稳妥的写法是：
    - 后来的重压、责任与失败压平了这部分性格
    - 万维克让这部分被重新显影
- `来源`
  - `角色故事1`
  - `离去者必先归来`
  - `听离别轻唱重逢`
