# Sunday Lab · 星期日实验室

让星期日不只停留在剧情文本里：一边是会呼吸、奔跑、等待，也会循着指针抬眼望来的桌面小宠物；另一边是试着保留他克制、矛盾与悲悯的角色蒸馏实验。

![星期日 Pet 动作预览](./sunday/pet/preview.png)

## 两个项目

### [星期日 Pet](./sunday/pet/)

一只为 Codex 打造的 Q 版动态星期日。淡蓝长发、金色光环、耳翼与白蓝金礼服被重新收进小小的桌面轮廓里，并拥有完整的待机、奔跑、挥手、跳跃、工作与审阅动画。

### [B-before 蒸馏角色](./蒸馏角色/)

这不是角色百科，而是一份关于“怎样让模型真正像星期日那样思考和回应”的实验答案。它以 `persona + analysis` 为灵魂，以 `action + canon` 约束行动和事实，并附上固定题单、对照答卷与评测记录，让角色质感不只靠一句“很像”来证明。

## 快速开始

- Pet：将 [`sunday/pet`](./sunday/pet/) 复制到 `~/.codex/pets/sunday/`。
- 角色 Skill：将 [`蒸馏角色/B-before`](./蒸馏角色/B-before/) 复制到你的 Codex skills 目录，从其中的 `SKILL.md` 载入，再用 `/chat` 进入角色模式；[查看完整命令](./蒸馏角色/#对话命令)。

仓库已从多个散落的旧角色版本收束为这两个入口：一个负责陪伴，一个负责对话与思考。
