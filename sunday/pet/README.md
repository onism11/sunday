# 星期日 Pet

> 把匹诺康尼的晨光，留在桌面的一角。

他不再站在高台上宣判秩序，而是化作一只会呼吸、奔跑、等待、审阅，并循着你的指针抬眼望来的小小星期日。

![星期日 Pet 动作预览](./preview.png)

## 它会做什么

- 9 组标准动画：待机、向左右奔跑、挥手、跳跃、失败、等待、工作与审阅。
- 16 个注视方向：目光会随着指针自然转动。
- 保留角色辨识度：淡蓝长发、金色光环、耳翼，以及白、深蓝与金色礼服。
- Q 版贴纸风格：柔和、干净，适合长期停留在桌面。

## 安装

将本目录复制为：

```text
~/.codex/pets/sunday/
```

保持下面两个运行文件位于同一目录：

```text
pet.json
spritesheet.webp
```

`preview.png` 只是动作预览，不参与运行。

## 技术规格

- Codex Pet schema：v2
- 精灵图：1536 × 2288 WebP，透明背景
- 单格尺寸：192 × 208
- 布局：8 列 × 11 行
- 动画行：完整覆盖 9 种标准状态
